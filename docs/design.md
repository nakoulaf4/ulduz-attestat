# Ulduz — Дизайн-система и спецификация интерфейса (`docs/design.md`)

**Ulduz** (азерб. *«Звезда»*) — веб-тренажёр для подготовки к выпускному экзамену ГЭЦ Азербайджана (**DİM Buraxılış / Аттестат**) по четырём предметам: **Математика**, **Русский язык**, **Английский язык**, **Азербайджанский язык**.

---

## 1. Бренд, характер и режим поверхности

- **Режим поверхности**: **Operate + Read** (ежедневная учебная рабочая среда + длинное чтение на русском, английском и азербайджанском языках).
- **Концепция**: *«Академическая ясность и каспийский свет»* — тёплая бумага в светлой теме (`#F7F6F2`) и глубокий ночной индиго в тёмной теме (`#0C1017`), спокойная иерархия без рекламных кикеров/eyebrow-плашек, вложенных карточек и декоративного шума.
- **Фирменный знак**: **восьмилучевая звезда «Ulduz»** (`ulduzStarSvg` в `site/js/app/icons.js`), поочерёдно зажигающая лучи `1..8` в ходе учебного спринта.

## 2. Цветовая палитра и семантические токены (WCAG 2.1 AA+)

Задаются через CSS Custom Properties в `site/css/styles.css` (`:root` и `[data-theme="dark"]`) вместе с `color-scheme: light / dark`, тематическими `::selection`, `caret-color`, `text-underline-offset: 0.18em` и тонкими скроллбарами.

| Токен | Light (Paper) | Dark (Night Sky) | Примечание |
|---|---|---|---|
| `--bg-canvas` | `#F7F6F2` | `#0C1017` | Основной фон страницы |
| `--bg-surface` | `#FFFFFF` | `#151B26` | Карточки заданий, верхняя панель, дровер |
| `--bg-subtle` | `#EFECE6` | `#1E2636` | Сегментные контролы, вторичные полосы |
| `--text-primary` | `#141821` | `#F0F4F8` | Основной текст и заголовки (> 15:1) |
| `--text-secondary` | `#434C5E` | `#B4C1D4` | Описания, подписи (≥ 8:1) |
| `--text-muted` | `#556072` | `#8E9CB2` | Метаданные и `::placeholder` (≥ 4.9:1 на всех поверхностях) |

### 2.2. Акценты, предметы и состояния проверки

- **Основной акцент**: `--accent-primary` (`#1D4ED8` / `#60A5FA`), `--on-primary` (`#FFFFFF` / `#091322`).
- **Золотой акцент Ulduz**: `--accent-gold` (`#B45309` / `#FBBF24`), `--accent-gold-text` (`#92400E` / `#FCD34D`), `--accent-gold-soft` (`#FEF3C7` / `rgba(251,191,36,0.14)`).
- **Предметы**:
  - `math`: `#1D4ED8` / `#60A5FA` (`∑`)
  - `ru`: `#B91C1C` / `#F87171` (`Я`)
  - `en`: `#6D28D9` / `#A78BFA` (`En`)
  - `az`: `#0F766E` / `#2DD4BF` (`Ə`)
- **Проверка ответа** (чистые `1px` семантические рамки + мягкая заливка шапки, без толстых левых полос):
  - Верно: `--state-correct` (`#15803D` / `#4ADE80`)
  - Частично: `--state-partial` (`#B45309` / `#FBBF24`)
  - Ошибка: `--state-wrong` (`#B91C1C` / `#F87171`)

## 3. Типографика и иконографика

- **Локальные шрифты (`site/vendor/fonts/`)** с полной кириллицей, азербайджанской расширенной латиницей (`ə ğ ı İ ö ş ü ç`) и KaTeX:
  - `--font-sans`: `Inter Variable` — весь интерфейс, кнопки, метаданные и `.tabular-nums` (`font-variant-numeric: tabular-nums` без подмены на моноширинный).
  - `--font-serif`: `Source Serif 4 Variable` — редакционные заголовки (`h1`, основные `h2`, заголовки текстов для чтения) и проза текстов для чтения (`.serif-prose`, `max-width: 68ch`).
  - `--font-mono`: `JetBrains Mono Variable` — строго для часов таймера, буквенных/числовых ключей и кодов ответов (`.mono-code`).
- **Фиксированная шкала `rem`** (без `clamp()`): главный заголовок `1.625rem` (mobile) / `2rem` (desktop), `h1` экранов `1.5rem / 1.75rem`, `h2` `1.25rem`. На заголовках `text-wrap: balance`, на описаниях и подзаголовках `text-wrap: pretty`.
- **Единая система SVG-иконок (`site/js/app/icons.js`)**: все иконки отрисованы в единой линии (`stroke="currentColor"`, `stroke-width="1.75"`, `round` caps/joins), без эмодзи и разнородных юникод-символов.

## 4. Макеты и ключевые компоненты

1. **Единая колонка задания**: не-текстовая `.task-card` ограничена `max-width: 780px; margin-inline: auto`.
2. **Чтение + Задание (Split-View)**:
   - На `≥ 1040px`: `52%` sticky `.passage-panel` (с плавным нижним градиентом прокрутки) и `48%` `.task-card`.
   - На `< 1040px`: липкий 2-вкладочный переключатель `Текст / Задание` с сохранением прокрутки каждой вкладки.
   - **Якоря предложений**: упоминания номеров предложений в вопросе (`предложение № 5`, `под номером 15`, `5-ci cümlə`) автоматически превращаются в кнопки, которые прокручивают и подсвечивают маркер `(N)` в тексте.
3. **Focused Exam Mode (режим экзамена)**:
   - Во время активного экзамена глобальная шапка и подвал скрываются (`body.is-exam-focused`), уступая место единой `54px` верхней панели (выход, предмет, таймер с паузой или режим «Без таймера», кнопка карты заданий, сдача).
   - При наличии текста для чтения (или ширине `< 1360px`) карта заданий открывается в выдвижном **slide-over drawer** (`.exam-drawer`, закрытие по `Esc`), исключая сжатие текста в три колонки.
4. **Интерактивные форматы (`task-view.js`)**:
   - `single` / `multi`: бумажное **вычёркивание лишних вариантов** (правый клик или скрытая кнопка при наведении/фокусе), сохранение фокуса при переключении, скрытие `<kbd>` после проверки.
   - `short`: контекстная панель символов (диакритика AZ только для `az`, знаки `− , / ;` только для `math`, скрыта для обычного `ru`/`en`), точное сравнение списков с запятой-десятичным разделителем (`1,5; 2,5` == `1.5; 2.5`).
   - `match`: выбор через пилюли `A–E` или кликом «левый пункт → правый вариант» с отображением назначенных номеров справа.
   - `order`: кнопки `↑ / ↓` с сохранением фокуса и обмен двух пунктов кликом.
   - `open`: шаги самооценки ДИМ по предмету (`0 / 0.67 / 1 / 1.33 / 2` для математики, `0 / 1 / 2` для языков), статус `pending` на результатах экзамена для написанных черновиков и полная синхронизация самооценки с `st.mistakes` и `st.stats`.
5. **Мобильная эргономика (`< 768px`)**: минимальные зоны касания `44×44px`, липкая нижняя панель действий `.task-card__footer`, однострочная горизонтальная лента номеров в Оригиналах и карточный вид таблицы истории экзаменов в Статистике (`< 640px`).
6. **Локализация и уведомления**: полный перевод интерфейса `RU / AZ` (`i18n.js`) с обновлением `<html lang>`, `document.title` и локали дат (`ru-RU` / `az-AZ`), живой бейдж ошибок в шапке (`#header-mistakes-badge`) и 5-секундный Undo-тост при удалении ошибок/закладок.
7. **Движение**: сдержанные переходы `150–200ms cubic-bezier(0.16, 1, 0.3, 1)` для состояний выбора, раскрытия объяснений, лучей звезды Ulduz и дровера — полностью отключаются при `prefers-reduced-motion: reduce`.
